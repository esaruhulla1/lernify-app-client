
# LerniFY

Learnify is a user-friendly and intuitive learning management app where users can change, manage, and learn.
The app features a dynamic network system, authentication, responsive UI, and a smooth user experience—which is convenient for both students and instructors.

## Features


- 🔔 Course Management
- 🔥 Next.js Powered
- 🎯 Clean & Modern UI
- ✅ User Authentication: Secure Login & Register, Form validation, 
- 📱 Responsive UI: Works smoothly on mobile, tablet, and desktop.
- 🎨 Clean & Modern Design: Simple interface with a soothing color theme.
